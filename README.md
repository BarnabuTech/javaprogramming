# Java Programming Learning Project

This repository contains a collection of Java programs created as part of a learning path for the Java Programming Language. Each folder represents a unit with a small project or exercise that focuses on a different set of Java concepts, such as basic syntax, object-oriented design, graphical user interfaces, and more.

## Project Structure

- `Unit-1/`
  - `QuizGame.java`
  - A simple quiz game program designed to practice basic Java syntax, control flow, user input, and console interaction.

- `Unit-2/`
  - `LibrarySystem.java`
  - A library management exercise that practices object-oriented design, collection handling, and basic program logic for managing books, users, or library operations.

- `Unit-3/`
  - `StudentRecordGUI.java`
  - A graphical student record program. This unit explores Java Swing GUI development and how to display or manage student information in a desktop interface.

- `Unit-4/`
  - `StockAnalysis.java`
  - A stock analysis or financial data program. This unit focuses on working with numbers, arrays or lists, and basic data processing in Java.

- `Unit-5/`
  - `Course.java`
  - `Student.java`
  - `CourseManagement.java`
  - `Main.java`
  - A course and student management application that demonstrates object-oriented programming with multiple classes, relationships between `Course` and `Student`, and program flow through a `Main` entry point.

- `Unit-6/`
  - `VehicleRentalSystem/`
    - `Car.java`
    - `CarVehicle.java`
    - `Truck.java`
    - `TruckVehicle.java`
    - `Motorcycle.java`
    - `MotorVehicle.java`
    - `Vehicle.java`
    - `Main.java`
  - A vehicle rental system that practices inheritance, class hierarchies, polymorphism, and modeling a real-world domain with different vehicle types.

- `Unit-7/`
  - `StudentManagementSystem/`
    - `Course.java`
    - `Student.java`
    - `StudentManagementGUI.java`
  - A student management system with a graphical interface, combining OOP concepts and GUI development to manage student and course details.

## Notes

- This project is intended as a learning portfolio for practicing Java programming fundamentals.
- Unit folders contain source code files and, in some cases, compiled `.class` files.
- To run a program, compile the `.java` files with `javac` and execute the desired class with `java`, for example:

```bash
javac Unit-1/QuizGame.java
java -cp Unit-1 QuizGame
```

## Learning Goals

- Understand Java syntax and control flow
- Build small interactive applications
- Use object-oriented programming with classes and inheritance
- Create simple GUI applications with Java Swing
- Manage program structure across multiple files and packages

Enjoy exploring the units and learning Java step by step!
